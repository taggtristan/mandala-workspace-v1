# Mandala Workspace v1 Rollout Final

This is the latest application source package for the Mandala Workspace master delivery.

## Included
- Next.js app
- Mandala branding
- internal project dashboard
- client portal preview
- vendor/client role model
- universal project templates
- project creation engine scaffold
- workbook sync API scaffold
- Google Apps Script sync endpoint
- mural estimate engine with exclusion areas
- event operations module
- VPS deployment guide
- rollout checklist
- workbook upgrade guide

## Run Locally

```bash
npm install
npm run dev
```

## Deploy on Vercel
Upload this folder to GitHub, then import it into Vercel as a Next.js project.
